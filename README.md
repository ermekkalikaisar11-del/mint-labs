**MINT Labs** (Math, Informatics, Next Technologies) — это open-source платформа для поиска экзопланет методом транзитов на основе открытых данных космических телескопов NASA (Kepler / TESS). 

Проект демонстрирует, что современные методы астрофизики и машинного обучения доступны не только крупным обсерваториям, но и независимым исследователям. 

> 🎯 **Цель проекта:** Создать инструмент уровня исследовательской лаборатории, работающий на обычном ноутбуке.

## ✨ Ключевые особенности (Key Features)

*   **Комплексный пайплайн:** От скачивания сырых данных (FITS) из архивов NASA MAST до генерации научного HTML-отчета.
*   **Умный поиск (BLS + Matched Filter):** Классический алгоритм BLS (Box-fitting Least Squares) для первичного поиска, усиленный авторским алгоритмом поиска по шаблону (Matched Filter) для распутывания мультипланетных систем.
*   **Анализ TTV (Transit Timing Variations):** Обнаружение гравитационного взаимодействия планет по сдвигам времени их транзитов.
*   **Кэширование данных:** Локальное сохранение скачанных массивов NASA в формат .npz для мгновенного повторного анализа.
*   **Профессиональный GUI:** Многопоточный интерфейс на Tkinter (защита от зависаний через queue.Queue) с интерактивными таблицами, графиками фазовой склейки и темной космической темой.
*   **Сверка с каталогом NASA:** Автоматическое сравнение найденных периодов с базой подтвержденных экзопланет.

## 🚀 Результаты (Proof of Concept)

Программа была протестирована на реальных данных мультипланетной системы **Kepler-90** (в ней 8 известных планет).

| :--- | :--- | :--- | :--- | :--- |
| **Kepler-90 b** | 7.008 д | 7.0088 д | 0.01% | ✅ Подтверждено |
| **Kepler-90 c** | 8.719 д | 8.7187 д | 0.01% | ✅ Подтверждено |
| **Kepler-90 d** | 59.737 д | 59.7366 д | 0.00% | ✅ Подтверждено |
| **Kepler-90 e** | 91.939 д | 91.9404 д | 0.00% | ✅ Подтверждено |

## 📂 Архитектура проекта

Проект разделен на независимые модули (Microservices Architecture) для легкости тестирования и поддержки:

*   mint_main.py — **Пульт управления** (GUI, Tkinter, Queue).
*   mint_engine.py — **Курьер** (Загрузка данных NASA, кэширование, первичная статистика).
*   mint_validator_core.py — **Судья** (BLS-поиск, итеративное вычитание планет, вердикты).
*   mint_matched_filter.py — **Детектив** (Поиск по шаблону, анализ TTV, слепой поиск).
*   mint_plotter.py — **Художник** (Интерактивные графики в GUI).
*   mint_reporter.py — **Секретарь** (Генерация HTML-отчетов и CSV таблиц).

## 🛠️ Установка и запуск

1. Клонируйте репозиторий:
   git clone https://github.com/ermekkalikaisar11-del/mint-labs.git
   cd mint-labs

2. Создайте виртуальное окружение и установите зависимости:
   python -m venv venv
   (Windows): .\venv\Scripts\activate
   (Linux/Mac): source venv/bin/activate
   pip install -r requirements.txt

3. Запустите приложение:
   python mint_main.py
